## `factor.hpp`

最小素因数テーブルを線形篩で構築する `yesantikiss::Factor` です。

- `build(n)`: `1` から `n` までの最小素因数を `O(N)` で構築
- `factorize(x)`: `(素因数, 指数)` の列を取得
- `factor_list(x)`: 重複込みの素因数列を取得
- `is_prime(x)`: 素数判定 `O(1)`
- `primes`: `n` 以下の素数列

素因数分解の計算量は、出力される素因数の個数に比例します。各問い合わせは事前に構築した範囲内の `1 <= x <= N` を対象とします。
