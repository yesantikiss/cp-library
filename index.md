## このライブラリについて

競技プログラミング向けの C++ ライブラリです。各ライブラリページでは、機能、
主な API、利用時の要件・注意事項、計算量を確認できます。

## 利用要件

- C++17 以降
- GCC または Clang
- 各ヘッダは単体で include 可能
- API ごとの添字範囲、事前構築、代数的要件などは各ページの
  「要件・注意」を参照

リポジトリのルートを include path に追加して利用します。

```cpp
#include "ds/compressor.hpp"
```
